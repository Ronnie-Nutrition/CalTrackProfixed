# App Store Assets Guide - CalTrackPro

## Required Assets for App Store Submission

### 📱 App Icon Requirements

#### Sizes Required:
- **App Store Icon**: 1024x1024px (PNG, no transparency, no rounded corners)
- **iPhone App Icons**: 180x180px, 120x120px, 87x87px
- **iPad App Icons**: 152x152px, 76x76px
- **Settings Icon**: 58x58px, 29x29px
- **Spotlight Search**: 120x120px, 80x80px, 40x40px

#### Design Guidelines:
- Simple, recognizable design
- Works well at small sizes
- Nutrition/food theme
- Clean, minimal aesthetic
- High contrast for visibility
- No text (iOS adds app name below)

### 📸 Screenshot Requirements

#### iPhone 6.7" (iPhone 15 Pro Max, 14 Pro Max, 13 Pro Max, 12 Pro Max)
- **Size**: 1290x2796px or 2796x1290px
- **Required**: 1-10 screenshots
- **Primary device** for App Store listing

#### iPhone 6.5" (iPhone 11 Pro Max, XS Max)
- **Size**: 1242x2688px or 2688x1242px
- **Required**: 1-10 screenshots

#### iPhone 5.5" (iPhone 8 Plus, 7 Plus, 6s Plus, 6 Plus)
- **Size**: 1242x2208px or 2208x1242px
- **Required**: 1-10 screenshots

#### iPad Pro (6th Gen) 12.9"
- **Size**: 2048x2732px or 2732x2048px
- **Required**: 1-10 screenshots (if supporting iPad)

#### iPad Pro (2nd Gen) 12.9"
- **Size**: 2048x2732px or 2732x2048px
- **Required**: 1-10 screenshots (if supporting iPad)

### 🎨 Design Specifications

#### Colors
- **Primary**: Blue (#007AFF) - iOS system blue
- **Secondary**: Green (#34C759) - for positive actions
- **Background**: White/System background
- **Text**: Black/System text colors

#### Typography
- **System Font** (San Francisco)
- **Headlines**: Bold, large sizes
- **Body**: Regular weight, readable sizes
- **Captions**: Smaller, secondary color

#### Visual Style
- **Clean and minimal**
- **Plenty of white space**
- **Consistent with iOS design language**
- **Professional nutrition app aesthetic**

## Asset Creation Process

### Phase 1: App Icon
1. Design 1024x1024 master icon
2. Generate all required sizes
3. Add to Xcode project
4. Test on device

### Phase 2: Screenshots
1. Set up iPhone simulator for largest screen size
2. Populate app with sample data
3. Take screenshots of key features
4. Add marketing text overlays
5. Resize for all required dimensions

### Phase 3: App Store Connect
1. Upload all assets
2. Add app descriptions
3. Set up metadata
4. Configure pricing and availability

## Asset Quality Checklist

### App Icon:
- [ ] 1024x1024px PNG
- [ ] No transparency
- [ ] No rounded corners (iOS adds them)
- [ ] High resolution, crisp details
- [ ] Recognizable at small sizes
- [ ] Consistent with app theme

### Screenshots:
- [ ] High resolution (exact pixel requirements)
- [ ] Show key app features
- [ ] Include compelling marketing text
- [ ] Consistent visual design
- [ ] All required device sizes
- [ ] Portrait orientation (recommended)

### Technical:
- [ ] PNG format for icons
- [ ] PNG or JPEG for screenshots
- [ ] sRGB color profile
- [ ] No copyright/trademark violations
- [ ] Family-friendly content
