## Guidelines

All PRDs follow the structure defined in [ai-dev-tasks/create-prd.md](https://github.com/snarktank/ai-dev-tasks):
1. Introduction/Overview
2. Goals
3. User Stories
4. Functional Requirements
5. Non-Goals (Out of Scope)
6. Design Considerations
7. Technical Considerations
8. Success Metrics
9. Open Questions

## Workflow

For new features:
1. Create PRD using the template
2. Generate task list using `generate-tasks.md`
3. Implement following `process-task-list.md`
4. Use conventional commits (feat:, fix:, docs:, etc.)
